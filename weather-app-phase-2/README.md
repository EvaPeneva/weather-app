# Weather App - Phase 2

Това е втора фаза на училищния проект Weather App.

Фаза 2 надгражда върху вече готовата Фаза 1. В тази стъпка основната промяна е, че JavaScript кодът е разделен на модули, за да бъде по-подреден и по-лесен за развитие.

## Файлова структура

```text
weather-app-phase-2/
├── index.html
├── styles.css
├── README.md
└── js/
    ├── app.js
    ├── api.js
    ├── ui.js
    └── weather-codes.js
```

## Какво е променено спрямо Фаза 1

- `script.js` вече не е главният файл за логиката.
- `index.html` зарежда `js/app.js` като ES module.
- API заявките са отделени в `api.js`.
- DOM промените са отделени в `ui.js`.
- Weather code логиката е отделена в `weather-codes.js`.
- DOM елементите са събрани в един обект.

## Важно за стартиране

Понеже проектът използва JavaScript модули, най-добре е да се стартира с Live Server във VS Code.
