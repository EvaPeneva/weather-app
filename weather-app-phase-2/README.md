# Weather App - Phase 1

Това е първа фаза на училищния проект по JavaScript, HTML и CSS.

## Какво има в проекта

- `index.html` - структура на страницата
- `styles.css` - дизайн и responsive оформление
- `script.js` - JavaScript логика, заявки към API и показване на данните

## Функционалности във Фаза 1

- Търсене на град по име
- Използване на Open-Meteo Geocoding API за координати
- Използване на Open-Meteo Forecast API за текущо време
- Показване на:
  - име на град
  - температура
  - условие на времето
  - скорост на вятъра
  - координати
  - икона според времето
- Loading съобщение
- Error съобщение при празно поле или несъществуващ град

## Как да се стартира

Отвори файла `index.html` в браузър.

За тест пробвай:

- Sofia
- London
- Paris
- несъществуващ град, за да видиш error съобщението
